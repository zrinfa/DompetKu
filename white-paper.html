DompetKu: Arsitektur Sistem Pencatatan Finansial Terdesentralisasi Berbasis Local-First dan Pemrosesan Kecerdasan Buatan Multimodal untuk Sektor Usaha Mikro

Fazrin Mauza Dwi Zuhudi
Program Studi S1 Pendidikan Teknologi Informasi, Universitas Negeri Surabaya & Rumah BUMN BNI Ngawi
Abstrak

Sektor Usaha Mikro, Kecil, dan Menengah (UMKM) menghadapi kendala klasik dalam tata kelola administrasi keuangan, khususnya percampuran arus kas personal dengan operasional bisnis serta friksi waktu pencatatan transaksi manual. Penelitian dan implementasi sistem DompetKu menyajikan solusi berupa platform Progressive Web App (PWA) dengan paradigma local-first. Seluruh data transaksi diisolasi pada mesin peramban pengguna melalui IndexedDB tanpa perantara peladen penyimpan terpusat. Untuk meminimalkan latensi pencatatan, sistem mengintegrasikan tiga jalur inferensi kecerdasan buatan: pemrosesan bahasa alami berbasis teks perintah cepat, optical character recognition untuk faktur fisik, serta streaming suara dua arah secara langsung. Redundansi arsip diakomodasi melalui protokol OAuth 2.0 yang menghubungkan klien langsung ke Google Drive pribadi pengguna. Hasil implementasi menunjukkan efisiensi waktu entri data, keterjaminan privasi finansial, dan stabilitas operasional pada kondisi jaringan nirkoneksi.

Kata Kunci: Local-First Architecture, Progressive Web App, Pencatatan Keuangan UMKM, Kecerdasan Buatan Multimodal, Zero-Knowledge Privacy.

1. Pendahuluan

Pencatatan keuangan yang tertib merupakan pondasi utama dalam evaluasi kelayakan usaha dan pertumbuhan skala bisnis UMKM. Kendati demikian, mayoritas pelaku usaha mikro di Indonesia masih mengandalkan pencatatan berbasis kertas atau bahkan tidak melakukan pencatatan sama sekali. Kendala mendasar yang ditemukan meliputi tingginya beban kognitif pengisian formulir akuntansi berlapis, kekhawatiran kebocoran data rahasia bisnis ke peladen pihak ketiga, serta ketidakstabilan konektivitas internet pada lokasi operasional.

Aplikasi berbasis komputasi awan murni (cloud-centric) menimbulkan ketergantungan mutlak pada ketersediaan jaringan dan membuka celah privasi. Untuk mengatasi disparitas tersebut, proyek DompetKu dirancang dengan memadukan arsitektur komputasi local-first dengan akselerasi otomatisasi kecerdasan buatan, memastikan integritas data berada dalam kontrol penuh pemilik perangkat.

2. Arsitektur Komputasi Local-First

Paradigma local-first menempatkan media penyimpanan lokal pengguna sebagai sumber kebenaran primer (primary source of truth). Diagram alur penyimpanan dan pemrosesan data dirancang sebagai berikut:

[Antarmuka Pengguna (PWA Klien)] │ ├── (Baca / Tulis Instan) ────────► [IndexedDB / LocalStorage Klien] │ │ ├── (Permintaan Ekstraksi AI) │ (Sinkronisasi Terenkripsi) │ │ ▼ │ [API AI Gateway] [Google Drive Pengguna] │ (Stateless Processing) (Pencadangan Mandiri Klien) │ │ └── (Hasil JSON Transaksi)

Implementasi arsitektur ini didasarkan pada tiga pilar fungsional:

  1. Kemandirian Penyimpanan Klien: Data transaksi, daftar pos kantong, preferensi profil, dan riwayat mutasi disimpan pada IndexedDB peramban. Operasi create, read, update, dan delete (CRUD) berjalan dengan latensi di bawah 15 milidetik karena dieksekusi secara lokal tanpa menunggu round-trip network.
  2. Ketahanan Luring Berkelanjutan: Menggunakan Service Worker untuk mengarsipkan bundel aset statis (HTML, skrip logika, gaya CSS, berkas pustaka grafik), sehingga aplikasi tetap dapat dimuat dan dioperasikan dalam kondisi tanpa jaringan internet.
  3. Kerahasiaan Nir-Peladen (Zero-Knowledge): Pengembang tidak menyediakan pangkalan data relasional untuk menghimpun data transaksi pengguna. Beban kepatuhan perlindungan data pribadi dialihkan ke sistem kendali pengguna secara mandiri.

3. Pipeline Otomatisasi Kecerdasan Buatan (AI)

Guna memangkas waktu pengisian formulir transaksi, DompetKu mengimplementasikan antarmuka multimodal yang terdiri dari tiga kanal masukan independen:

3.1 Ekstraksi Teks Bahasa Alami (NLP Parsing)

Pengguna menginput kalimat perintah natural tanpa format kaku. Masukan dikirimkan ke model pemrosesan bahasa alami yang dikonfigurasikan dengan instruksi sistem ketat untuk mengekstraksi objek data bertipe terstruktur:

  • Nominal numerik (mengonversi satuan percakapan seperti 'ribu', 'k', 'jt' menjadi integer murni).
  • Tipe transaksi (Pemasukan atau Pengeluaran).
  • Kategori pembukuan (contoh: Bahan Baku, Operasional, Penjualan Produk).
  • Pos alokasi kantong (Usaha atau Pribadi).

3.2 Pengenalan Karakter Optis Citra Struk (Vision OCR)

Pemindaian dokumen bukti transaksi fisik diproses melalui model visi komputer. Model melakukan segmentasi citra terhadap area nama gerai, daftar butir belanjaan, stempel tanggal, serta nominal agregat akhir, lalu menghasilkan skema formulir verifikasi sebelum dilakukan persistensi ke penyimpanan lokal.

3.3 Antarmuka Suara Interaktif Waktu-Nyata (Live Call Voice AI)

Jalur komunikasi suara memanfaatkan streaming audio dua arah dengan latensi rendah. Aliran suara percakapan diterjemahkan ke teks secara simultan, diinterpretasikan intensinya untuk pemanggilan fungsi (function calling) mutasi keuangan, dan dijawab kembali dengan sintesis audio alami.

4. Tata Kelola Akuntansi dan Mekanisme Cadangan

Sistem membedakan dua entitas kantong finansial utama: Kas Usaha dan Kas Pribadi. Setiap transaksi terikat pada satu kantong spesifik untuk mencegah bias kalkulasi margin laba bersih.

Parameter Kantong Usaha Kantong Pribadi
Fungsi Utama Operasional perdagangan, bahan baku, modal kerja Kebutuhan rumah tangga, konsumsi individual
Perhitungan Laba Bersih Dihitung (Pemasukan dikurangi Pengeluaran Operasional) Diisolasi dari laba rugi usaha
Output Pelaporan Buku kas harian usaha, rekap laba kotor, ekspor CSV/PDF Catatan pengeluaran personal

Untuk mitigasi risiko kehilangan perangkat fisik atau pembersihan cache peramban, DompetKu memanfaatkan protokol otorisasi OAuth 2.0 milik Google Identity Services. Pengguna dapat menghubungkan akun Google Drive pribadi mereka secara langsung. Berkas cadangan yang memuat snapshot basis data lokal diunggah langsung ke penyimpanan awan Pengguna tanpa perantara peladen pihak ketiga.

5. Evaluasi Kinerja dan Karakteristik Teknis

Tinjauan parameter teknis implementasi disarikan pada tabel matriks sistem berikut:

Komponen Sistem Spesifikasi Teknis Tujuan dan Karakteristik
Model Aplikasi Progressive Web App (PWA) Standalone Dapat diinstalasi pada sistem operasi mobile tanpa dependensi app store
Penyimpanan Klien IndexedDB & LocalStorage API Akses data transaksi instan tanpa latensi koneksi jaringan
Model Pemrosesan AI Stateless Remote Inference Pipeline Kerahasiaan data terjamin, rekaman masukan tidak dijadikan arsip server
Pencadangan Awan Google Drive REST API via OAuth 2.0 Desentralisasi penyimpanan cadangan langsung ke hak milik pengguna
Format Ekspor CSV (RFC 4180) & PDF Rendering Klien Kompatibilitas universal dengan perangkat lunak akuntansi spreadsheet

6. Kesimpulan dan Arah Pengembangan

Platform DompetKu membuktikan bahwa integrasi komputasi local-first dengan modul kecerdasan buatan multimodal mampu menjawab tantangan adopsi pencatatan keuangan pada segmen usaha mikro. Sistem ini berhasil memangkas hambatan manualitas entri data sekaligus menjamin kedaulatan privasi finansial pengguna secara penuh.

Arah pengembangan lanjutan mencakup pengayaan algoritma deteksi tren arus kas berbasis pembelajaran mesin lokal (in-browser machine learning) serta format sinkronisasi terenkripsi peer-to-peer antarperangkat dalam satu ekosistem usaha.
